# My Dotfiles!

A modern, modular desktop environment built on **Hyprland** and **Quickshell**.

## Features

- Modular Dashboard
- Native Audio Controls (PipeWire)
- Bluetooth Manager
- Wi-Fi & Ethernet Manager
- Notification Center
- Calendar Panel
- System Tray (StatusNotifierItem)
- Clipboard History
- Music Controls (MPRIS)
- Hardware Sensors
- Power Profiles
- Dynamic Wallpapers
- Touchpad Gestures
- IPC Integration

---

## Required Dependencies

| Package | Purpose |
|---------|---------|
| hyprland | Wayland compositor |
| quickshell | Shell framework |
| hyprlock | Lock screen |
| hypridle | Idle daemon |
| hyprshutdown | Power menu |
| hyprpicker | Color picker |
| qt6-wayland | Qt Wayland backend |
| pipewire-alsa | Audio backend |
| playerctl | MPRIS integration |
| networkmanager | Network management |
| bluez | Bluetooth daemon |
| bluez-utils | Bluetooth utilities |
| power-profiles-daemon | Power profile management |
| brightnessctl | Brightness control |
| cliphist | Clipboard history |
| wl-clipboard | Wayland clipboard |
| xdg-desktop-portal-hyprland | Desktop portal |
| ttf-jetbrains-mono-nerd | Required icons |
